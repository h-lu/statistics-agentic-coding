## 1. 为什么标准误会随着样本量增大而变小？

设独立同分布的样本为 `X_1, X_2, ..., X_n`，每个样本的方差都是 `σ^2`。

样本均值是：

```text
\bar{X} = (X_1 + X_2 + ... + X_n) / n
```

因为独立样本的方差可以相加，所以：

```text
Var(\bar{X}) = Var((X_1 + ... + X_n) / n)
             = (1 / n^2) * Var(X_1 + ... + X_n)
             = (1 / n^2) * (Var(X_1) + ... + Var(X_n))
             = (1 / n^2) * (nσ^2)
             = σ^2 / n
```

所以样本均值的标准差就是：

```text
SD(\bar{X}) = σ / sqrt(n)
```

这就是标准误的来源。实际中我们不知道 `σ`，通常用样本标准差 `s` 代替，于是得到：

```text
SE ≈ s / sqrt(n)
```

这也解释了为什么样本量越大，标准误越小。

## 2. 为什么"至少一个假阳性"是 `1 - (1 - α)^m`？

如果你做 `m` 次独立检验，每次检验在零假设成立时的假阳性概率都是 `α`，那么单次检验不出错的概率是：

```text
1 - α
```

如果这 `m` 次检验彼此独立，那么它们都不出错的概率就是：

```text
(1 - α)^m
```

因此，至少出现一个假阳性的概率就是：

```text
1 - (1 - α)^m
```

这就是 Week 05 里"检验次数越多，假阳性风险越大"的数学原因。
