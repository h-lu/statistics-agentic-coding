# Week 11 Tree Model Studio 交互页设计

## 设计定位

Week 11 不再沿用 Week 09 的“多个小实验页”形式，而是做成一个完整的 **模型研究工作台（Tree Model Studio）**。

它不是 dashboard，也不是炫技页面，而是一个课堂用的“统计模型实验仪器”：学生可以调参数、看边界、比较指标、读风险提示，最后形成模型选择判断。

## 单页结构

源文件：`interactive/tree_model_studio.html`

站点发布路径：`/stat/interactives/week_11/tree_model_studio.html`

- 单文件 HTML，内置 CSS/JS，可离线打开。
- 不依赖 CDN、不需要构建流程。
- 通过模块导航切换 6 个实验。
- 支持 hash 定位：`#boundary`、`#pruning`、`#instability`、`#forest`、`#baseline`、`#importance`。

## 视觉原则

- 风格：干净、克制、实验室感。
- 背景：温暖浅灰，不使用 Week09 那种厚重卡片和按钮堆叠。
- 主色：蓝色用于模型/训练，橙色用于测试/风险，绿色用于稳定。
- 信息层级：先给判断，再给图，再给参数。
- 交互反馈：每个模块都有“当前结论”和“课堂追问”。

## 页面布局

```text
顶部：课程 / 标题 / 模式切换
左侧：6 个实验模块导航 + 本节学习路径
中间：主实验画布 + 当前判断
右侧：参数控制台 + 指标卡
底部：学生实验任务 / 课堂讨论问题
```

## 六个模块

1. **决策边界**：看树如何用阶梯边界切分二维空间。
2. **分裂与剪枝**：理解 impurity、叶子数、复杂度惩罚。
3. **单棵树不稳定**：轻微扰动数据后，树结构和边界可能变化。
4. **随机森林**：多棵树投票如何降低边界抖动。
5. **Baseline 对战**：复杂模型必须和多数类、单特征、逻辑回归比较。
6. **特征重要性陷阱**：Gini importance、Permutation importance、泄漏变量、高基数变量的风险。

## 教学主线

```text
树会切空间
→ 树会越长越复杂
→ 单棵树很不稳定
→ 森林用投票降低方差
→ 复杂模型要打 baseline
→ 特征重要性也需要审查
```

## 可接受的教学近似

页面中的数据与模型指标用于课堂直觉演示，不替代 sklearn/statsmodels 的正式计算。正式作业和报告仍以 Python 代码输出为准。
