# Week 09 独立 HTML 交互页设计稿

目标：为 Week 09「模型不是魔法——回归分析与诊断」配套若干**单文件、可离线打开、无需构建流程**的交互式 HTML 页面。每个页面聚焦一个课堂概念，适合 5–12 分钟课堂演示，也适合学生课后自测。

## 设计原则

1. **单页独立**：每个 `.html` 文件自带 CSS/JS/SVG，不依赖后端；优先不使用外部 CDN，避免课堂网络问题。
2. **教学先于炫技**：交互只服务于概念理解，不做复杂 dashboard。
3. **即时反馈**：学生拖动滑块/点位后，回归线、残差、R²、VIF、诊断提示立即变化。
4. **避免因果误导**：所有页面默认用「关联 / 条件关联 / 预测关系」，不用「影响」暗示因果。
5. **可截图入课件**：页面应有清晰标题、短结论区、导出 PNG 或至少适合浏览器截图。
6. **统计口径一致**：与 Week 09 正文一致：本周重点是 OLS 解释、诊断、多元回归、共线性和交互项；泛化评估只做 Week 10 预告。

## 页面 1：OLS Line Lab —— 为什么这条线是“最好”的？

**文件名**：`01_ols_line_lab.html`

### 教学目标

- 让学生看到 OLS 不是魔法，而是在最小化残差平方和 SSE。
- 区分「残差」和「误差」。
- 直观看到离群点/高杠杆点如何拉动回归线。

### 核心交互

1. 散点图中预置 12–20 个点。
2. 学生可以：
   - 拖动任意点；
   - 点击添加点；
   - 一键加入高杠杆点；
   - 切换「显示残差竖线」。
3. 页面实时显示：
   - OLS 回归线；
   - SSE；
   - 斜率、截距；
   - R²；
   - 当前被拖动点的残差。
4. 可选高级交互：
   - 手动拖动一条“候选线”，比较候选线 SSE 与 OLS SSE。

### 页面布局

- 左侧：散点图 + OLS 线 + 残差线。
- 右侧：指标卡片（斜率、截距、SSE、R²）。
- 底部：三个按钮：`重置数据`、`加入高杠杆点`、`显示/隐藏残差`。
- 右下角：一句动态解释，例如：
  > 当前高杠杆点把斜率从 1.2 拉到 0.5：这说明点的位置不只是“异常”，还会改变模型结论。

### 课堂用法

- 先让学生猜哪条线最好，再打开残差平方和。
- 加入高杠杆点，追问：这个点是不是“错数据”？如果不是，应该删除吗？

### 实现要点

- 用 Canvas 或 SVG 绘图；建议 SVG，方便文字和拖拽。
- OLS 计算公式直接 JS 实现：均值、协方差、方差、SSE、SST、R²。
- 坐标系固定，避免拖动时画布缩放影响理解。

## 页面 2：Residual Diagnostics Lab —— 残差图诊断诊所

**文件名**：`02_residual_diagnostics_lab.html`

### 教学目标

- 训练学生用残差图识别 LINE 假设问题。
- 把「线性」「等方差」「异常点」「非正态」从抽象术语变成可见模式。

### 核心交互

1. 四种数据生成场景：
   - 线性且等方差；
   - 非线性关系；
   - 扇形异方差；
   - 含高影响点。
2. 学生切换场景后，页面显示：
   - 原始散点 + 回归线；
   - 残差 vs 拟合值图；
   - QQ 图简化版；
   - Cook's distance 棒图简化版。
3. 页面提供「诊断选择题」：
   - 主要问题是什么？
   - 下一步应该做什么？
4. 提交后给即时反馈。

### 页面布局

- 顶部：场景选择器。
- 中部 2x2 图阵：散点图、残差图、QQ 图、Cook's 图。
- 右侧：诊断问答卡。
- 底部：一句课后提醒：
  > 诊断图不是为了“证明模型正确”，而是为了发现模型哪里不可信。

### 课堂用法

- 教师先隐藏场景标签，只给图，让学生投票判断问题。
- 再揭示数据生成机制，解释为什么残差图比单看 R² 更有信息。

### 实现要点

- 数据直接由 JS 伪随机生成；为可复现，使用固定 seed 的简单 PRNG。
- QQ 图可以用近似正态分位数或预计算表，不追求完全精确。
- Cook's distance 可用教学近似，页面注明“用于可视化教学，正式计算以 statsmodels 为准”。

## 页面 3：R² Prediction Trap —— R² 高就一定好吗？

**文件名**：`03_r2_prediction_trap.html`

### 教学目标

- 为 Week 10 铺垫：样本内 R² 不等于泛化能力。
- 让学生看到模型复杂度、噪声、离群点会让训练集指标误导人。

### 核心交互

1. 学生调节：
   - 噪声大小；
   - 样本量；
   - 多项式阶数（1、2、5、10）；
   - 训练/测试划分比例。
2. 页面实时显示：
   - 训练点和测试点；
   - 拟合曲线；
   - Train R²；
   - Test RMSE 或 Test R²。
3. 提供一个按钮：`制造一个漂亮但危险的模型`，自动设置小样本 + 高阶多项式。

### 页面布局

- 左侧：训练/测试散点 + 拟合曲线。
- 右侧：滑块与指标。
- 底部：红/黄/绿风险提示：
  - 绿：训练和测试表现接近；
  - 黄：训练好、测试一般；
  - 红：训练极好、测试很差，疑似过拟合。

### 课堂用法

- Week 09 结尾演示 5 分钟：告诉学生“下周我们会系统处理这个坑”。
- 强调本周 OLS 诊断偏解释/假设，下周再讲验证集、交叉验证和数据泄漏。

### 实现要点

- 简单多项式拟合可用最小二乘矩阵求解；为避免数值复杂，也可预置几种曲线拟合结果。
- 如果实现成本要低，MVP 只支持线性/二次/五次三档。

## 页面 4：Multicollinearity VIF Lab —— 自变量“打架”时发生什么？

**文件名**：`04_multicollinearity_vif_lab.html`

### 教学目标

- 说明多重共线性不是一定让预测变差，而是让系数解释变不稳定。
- 让学生理解 VIF 的直觉：某个自变量能被其他自变量解释得越好，它自己的系数越不稳。

### 核心交互

1. 滑块控制两个自变量的相关程度 `corr(x1, x2)`：0、0.3、0.7、0.95。
2. 每次点击 `重新抽样`，页面重新生成数据并拟合：
   - `y ~ x1 + x2`
3. 实时显示：
   - x1/x2 散点；
   - x1、x2 的系数估计和置信区间；
   - VIF；
   - p 值变化。
4. 可选：用小动画重复抽样 100 次，显示系数估计分布变宽。

### 页面布局

- 左侧：x1 vs x2 相关散点。
- 中部：系数条形图 + 置信区间。
- 右侧：VIF 仪表盘。
- 底部：解释：
  > 当 x1 和 x2 高度相关时，模型很难区分“谁贡献了多少”。预测可能仍然不错，但单个系数解释会变危险。

### 课堂用法

- 先让相关度从 0 拉到 0.95，看 VIF 和 CI 变宽。
- 追问：如果业务上 x1/x2 都重要，应该删掉一个吗？引出领域判断、变量合成、正则化等后续主题。

### 实现要点

- 用 Cholesky 或简单构造：`x2 = rho*x1 + sqrt(1-rho^2)*noise`。
- VIF 计算：对每个自变量用其他自变量回归得到 R²，`VIF = 1/(1-R²)`。

## 页面 5：Interaction Terms Explorer —— 交互项不是“再加一个变量”

**文件名**：`05_interaction_terms_explorer.html`

### 教学目标

- 让学生理解 `x1 * group` 或 `x1 * x2` 的含义：一个变量的斜率取决于另一个变量。
- 区分主效应与交互效应。

### 核心交互

1. 两组数据：A 组和 B 组。
2. 学生调节：
   - A 组斜率；
   - B 组斜率；
   - 组间截距差；
   - 噪声。
3. 页面实时显示：
   - 两组散点和两条回归线；
   - 模型形式：`y = β0 + β1 x + β2 group + β3 x:group`；
   - 当前 `β3` 是否明显不为 0 的直觉提示。
4. 提供三个预设：
   - 只有截距差；
   - 只有斜率差；
   - 截距和斜率都不同。

### 页面布局

- 左侧：两组散点 + 两条线。
- 右侧：滑块和模型方程。
- 底部：解释卡：
  > 如果两条线平行，通常是组别主效应；如果斜率不同，才是交互项的核心。

### 课堂用法

- 先展示平行线，让学生解释 `group`。
- 再让两条线不平行，引出 `x:group`。
- 最后连接 Week 09 作业中“promotion × ad_spend”之类商业场景。

### 实现要点

- 不需要真实拟合复杂模型；MVP 可直接由滑块生成真实参数并显示拟合直觉。
- 进阶版再加入 OLS 估计和置信区间。

## 推荐实施顺序

### MVP：先做 3 个，足够支撑第 9 周课堂

1. `01_ols_line_lab.html`：最小二乘和残差直觉。
2. `02_residual_diagnostics_lab.html`：LINE 假设与诊断图。
3. `04_multicollinearity_vif_lab.html`：多元回归/VIF 的核心风险。

### 第二批：用于收尾和拓展

4. `03_r2_prediction_trap.html`：Week 10 预告。
5. `05_interaction_terms_explorer.html`：交互项专项。

## 每页统一 UI 规范

- 页面宽度：桌面优先，最小支持 1280px；移动端只保证可阅读。
- 字体：系统字体，中文优先：`-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans CJK SC", sans-serif`。
- 色彩：
  - 主色：深蓝 `#2563eb`；
  - 警示：橙色 `#f97316`；
  - 风险：红色 `#dc2626`；
  - 背景：浅灰 `#f8fafc`。
- 每页必须有：
  - 标题；
  - 3 行以内的学习目标；
  - 一个主交互区；
  - 一个“当前结论”解释框；
  - 一个“课堂提问”框。

## 共同 JS 工具建议

虽然页面要求独立 HTML，但可以把以下函数复制到每个页面，保持实现一致：

- `mean(arr)`
- `variance(arr)`
- `linearRegression(points)`
- `rSquared(points, model)`
- `residuals(points, model)`
- `seededRandom(seed)`
- `normalRandom(seed)`
- `matrixSolve(A, b)`：只在多元回归/VIF 页面需要。

## 验收标准

每个 HTML 页面完成后至少满足：

1. 双击本地文件可打开，无需服务器。
2. 无外部网络依赖。
3. Chrome/Edge/Safari 最近版本可用。
4. 页面首次打开即有默认数据和默认图。
5. 所有按钮/滑块/拖拽操作不会报错。
6. 页面上至少有一句动态解释，不只是图形变化。
7. 统计表述不使用未经限定的因果语言。
